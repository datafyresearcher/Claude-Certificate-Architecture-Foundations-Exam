## How to Evaluate a Community Resource

Before relying on a community resource:

1. Check when it was last updated and whether its links still work.
2. Compare technical claims with Anthropic's current documentation and exam guide.
3. Prefer resources that explain architectural trade-offs instead of only supplying answers.
4. Treat practice questions as learning aids, not as predictions of live exam content.
5. Review licenses before copying community code or documentation into another project.
