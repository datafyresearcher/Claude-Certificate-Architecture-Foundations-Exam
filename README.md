# Claude Certificate Architecture Foundations Exam

> A focused preparation repository for the Claude Certified Architect Foundations (CCA-F) exam. This repo collects the study guide, video modules, practice-test resource, and a suggested roadmap for working through the material.

## Disclaimer

This repository is a personal study hub. It is designed to organize learning resources and revision flow for CCA-F preparation; it is not an official certification repository and does not guarantee exam results.

## Roadmap

1. Start with the guide
   - Read the local study guide: [guide_en.pdf](CCA-F%20Exams%20Prepration/guide/guide_en.pdf)
   - Note the key exam domains, terminology, and practical architecture patterns.

2. Complete the video modules
   - Go through all 20 modules in order.
   - Pause after each module and write down the main concept, one practical example, and one possible exam-style question.

3. Practice applied scenarios
   - Focus on prompt design, Claude API usage, structured outputs, tool use, multi-agent patterns, MCP, Claude Code workflows, and evaluation tradeoffs.
   - Revisit scenario-based modules until you can explain the architecture decisions without notes.

4. Take practice tests
   - Use the Udemy practice tests after completing the guide and videos.
   - Review every missed question and map it back to the relevant module or guide section.

5. Final review
   - Re-read weak areas.
   - Review structured output, JSON schemas, tool integrations, lifecycle hooks, CI/CD workflows, and agent orchestration.
   - Do a final practice-test pass before exam day.

## Suggested Study Plan

### Pass 1: Orientation

1. Read the guide once from start to finish.
2. Watch Modules 1-5.
3. Create a glossary of Claude, architecture, prompt, API, and tool-use terms.

### Pass 2: Architecture and Implementation

1. Watch Modules 6-14.
2. Focus on multi-agent orchestration, tool integration, lifecycle hooks, and applied scenario reasoning.
3. Practice explaining why a particular Claude architecture fits a customer problem.

### Pass 3: Claude Code and Structured Output

1. Watch Modules 15-20.
2. Review Claude Code workflows, team configuration, MCP, Plan Mode, structured output, and JSON schema usage.
3. Build short mental checklists for design, evaluation, reliability, and handoff.

### Pass 4: Practice and Review

1. Complete the Udemy practice tests.
2. Rewatch the modules linked to missed concepts.
3. Re-read the guide sections connected to weak areas.
