# CCA-F Learning Folder

Start here when studying for the Claude Certified Architect - Foundation exam.

## Exam Integrity

Use this repository for preparation only. The protected exam does not allow AI assistance, external help, or unauthorized reference material. Practice until the architectural patterns are internalized well enough to answer from memory and judgment.

## Recommended Study Sequence

1. Read the guide PDF carefully: [guide_en.pdf](../guide/guide_en.pdf)
2. Watch all 20 YouTube modules: [Youtube Link.txt](../Youtube%20Tutorial/Youtube%20Link.txt)
3. Review the slide decks: [slide decks](../slide%20decks/)
4. Work through the local 60-question guide: [60-questions.md](60-questions.md)
5. Study the Claude Code documentation: <https://code.claude.com/docs/en/overview>
6. Take the free practice test: <https://claudecertifications.com/claude-certified-architect/practice-questions#main-content>
7. Take the practice tests: [Udemy Link.txt](../Udemy-CCA-F-6%20Practice%20Tests/Udemy%20Link.txt)
8. Take the 25 Google Forms practice tests: [practice-tests.md](practice-tests.md)
9. Complete free Anthropic courses: <https://anthropic.skilljar.com/>

## Core Competency Checklist

- Claude foundations and model behavior
- Prompt engineering and prompt design
- Claude API usage and model context management
- Agentic application architecture
- Claude Agent SDK concepts
- Multi-agent orchestration and subagent delegation
- Tool design, schema design, and tool-use reliability
- Lifecycle hooks and deterministic enforcement
- Claude Code team workflows, CI/CD, and repository automation
- Skills and reusable workflow packaging
- MCP server integrations
- Plan Mode and human-in-the-loop review
- Reliable structured output
- JSON Schema design for extraction and tool use
- Context compression, stale data handling, and long-running sessions
- Production error handling, retries, escalation, observability, and cost controls
